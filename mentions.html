11 / Cadre de l’exercice

Une entreprise inventée.
Un entretien à préparer.

Sélance Électronique est un scénario pédagogique de jeu de rôle professionnel.

Une fiction complète

Le nom, le logo, l’entreprise, les personnes, l’adresse, les produits, les réalisations, les dates, les effectifs et l’offre d’emploi sont fictifs. Ce site ne représente aucune entreprise réelle et ne propose aucun recrutement effectif.

Les informations de rémunération, d’organisation et d’horaires servent uniquement au jeu de rôle. Elles ne constituent pas des données sur le marché de l’emploi.

Coordonnées de scénario

L’adresse postale est inventée. Les adresses électroniques utilisent le domaine réservé .example ; elles ne sont pas destinées à l’envoi de messages. Le plan n’est pas une carte d’accès réelle.

Votre carnet

Le carnet conserve les notes dans le stockage local de votre navigateur, si ce stockage est disponible. Il peut produire un fichier texte à votre demande. Aucun formulaire ne transmet les notes, de CV ou de candidature.

Le site utilise une police externe quand la connexion le permet, avec une police de remplacement disponible. Il n’intègre pas d’outil de mesure d’audience.

Version du scénario

Édition du 11 novembre 2026. Le site public ne contient pas le corrigé ni les pièces personnelles utilisées pour préparer l’exercice.
